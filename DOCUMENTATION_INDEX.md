## 🔑 Key Terminology

To help you understand the documentation:

- **QCPP** - Quantum Coherence Protein Predictor (physics-based system)
- **UBF** - Universal Behavioral Framework (agent-based system)
- **Consciousness Coordinates** - (frequency, coherence) driving agent behavior
- **Mapless Navigation** - O(1) move generation without spatial maps
- **QCP** - Quantum Coherence Parameter (QCPP's main metric)
- **RMSD** - Root Mean Square Deviation (structure comparison metric)
- **GDT-TS** - Global Distance Test Total Score (validation metric)
- **TM-score** - Template Modeling score (structural similarity)
- **Phi (φ)** - Golden ratio (1.618...), used in geometric analysis
- **THz spectrum** - Terahertz frequency spectrum (QCPP output)
