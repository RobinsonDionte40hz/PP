# EmergentFolds Logo Assets

This directory contains the EmergentFolds branding assets.

## Files

### `emergentfolds-logo.svg`
Full horizontal logo with text "EmergentFolds" and protein helix icon
- **Usage**: Login/Register pages, marketing materials, headers
- **Dimensions**: 600 x 400 px
- **Colors**: 
  - #293B5F (Deep Navy) - Primary Dark
  - #47597E (Slate Blue) - Primary
  - #B2AB8C (Warm Beige) - Accents

### `emergentfolds-icon.svg`
Simplified icon version with just the protein helix structure
- **Usage**: Favicon, app icons, small UI elements
- **Dimensions**: 380 x 380 px (square)
- **Colors**: Same as full logo

## Color Palette

- **#293B5F** - Deep Navy (Primary Dark)
- **#47597E** - Slate Blue (Primary)
- **#DBE6FD** - Light Blue (Accent/Background)
- **#B2AB8C** - Warm Beige (Secondary)

## Design Elements

The protein helix structure symbol represents:
- **Helical Ribbons**: Protein secondary structure and folding
- **Emergent Patterns**: The emergent properties of protein structure from sequence
- **Intersecting Paths**: Multi-system integration (QCPP + UBF)
- **Golden Ribbons**: Phi-based quantum coherence patterns

## Usage Guidelines

1. **Dark Mode**: Logo automatically brightens for better visibility
2. **Minimum Size**: Don't scale below 24px height for full logo, 16px for icon
3. **Clear Space**: Maintain padding equal to the helix's width around the logo
4. **Color Variations**: Maintain original colors for brand consistency
