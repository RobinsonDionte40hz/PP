# WeFold Logo Assets

This directory contains the WeFold branding assets.

## Files

### `wefold-logo.svg`
Full horizontal logo with text "wefold" and tagline "PHYSICS BASED PROTEINS SHAPE BUILDER"
- **Usage**: Login/Register pages, marketing materials, headers
- **Dimensions**: 1408 x 768 px
- **Colors**: 
  - #47597E (Slate Blue) - Main text
  - #DBE6FD (Light Blue) - Particles
  - #B2AB8C (Warm Beige) - Accents

### `wefold-icon.svg`
Simplified icon version with just the atom structure
- **Usage**: Favicon, app icons, small UI elements
- **Dimensions**: 380 x 380 px (square)
- **Colors**: Same as full logo

## Color Palette

- **#293B5F** - Deep Navy (Primary Dark)
- **#47597E** - Slate Blue (Primary)
- **#DBE6FD** - Light Blue (Accent/Background)
- **#B2AB8C** - Warm Beige (Secondary)

## Design Elements

The atom/protein structure symbol represents:
- **Orbits**: Quantum mechanics and physics-based modeling
- **Particles**: Atomic structure and protein building blocks
- **Intersecting paths**: Multi-system integration (QCPP + UBF)

## Usage Guidelines

1. **Dark Mode**: Logo automatically brightens for better visibility
2. **Minimum Size**: Don't scale below 24px height for full logo, 16px for icon
3. **Clear Space**: Maintain padding equal to the atom's radius around the logo
4. **Color Variations**: Maintain original colors for brand consistency
